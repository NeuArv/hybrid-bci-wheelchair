## Third-Party Components

### NeuroPy Library

This project includes a modified version of the NeuroPy library for interfacing with Neurosky Mindwave headsets.

- **Original source**: https://github.com/lihas/NeuroPy
- **Modifications**: Updated for Python 3 compatibility, modernized code style, added documentation

### Hardware Components

This software is designed to work with:

- **Neurosky Mindwave Mobile 2**: EEG headset (trademark of NeuroSky, Inc.)
- **Raspberry Pi**: Single-board computer (trademark of Raspberry Pi Foundation)
- **HC-SR04**: Ultrasonic sensor module
