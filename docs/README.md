# Documentation

This directory contains supplementary documentation for the Hybrid BCI Wheelchair project.

## Available Documentation

### [Hardware Setup Guide](hardware_setup.md)

Comprehensive guide for:
- Bill of materials
- Raspberry Pi configuration
- GPIO pin assignments
- Motor driver wiring
- Ultrasonic sensor connections
- EEG headset pairing
- Power supply design
- Safety considerations

### [API Documentation](API.md)

Complete API reference for:
- `NeuroPy` - EEG headset interface
- `MotorController` - Motor control
- `BlinkDetector` - Blink detection
- `ObstacleDetector` - Obstacle avoidance

Includes usage examples and function signatures.
